01 · Pregunta inicial

¿Qué debe predecir el modelo?

Si conocemos los ángulos de las articulaciones q, queremos calcular la posición y orientación de la herramienta respecto de la base: T_base_herramienta(q).

En el robot

La escena entrega las posiciones articulares y la pose real de la herramienta.

En Python

El estudiante construye una cadena de transformaciones y compara su predicción con la escena.

Acuerdo previo de la clase: usar DH estándar, metros, radianes y una configuración cero definida. La base y la herramienta deben estar identificadas en la escena entregada.

02 · Una articulación

Cuatro parámetros entre referencias consecutivas

θi: giro alrededor de z anterior. En una articulación rotativa cambia con q[i].

di: avance sobre ese mismo eje z.

ai: distancia entre ejes z medida sobre el eje x nuevo.

αi: giro entre esos ejes z alrededor de x nuevo.

Aᵢ = Rz(θᵢ) · Tz(dᵢ) · Tx(aᵢ) · Rx(αᵢ)

Para la articulación i, el eje z de la referencia anterior coincide con su eje físico de movimiento. Las superficies del modelo 3D ayudan a orientarse, pero los ejes y la configuración cero determinan la tabla.

03 · Ensayo pequeño

Un brazo plano de dos articulaciones

Supón dos eslabones de longitudes L1 = 2 y L2 = 1. Todos los ejes de giro son paralelos: d = 0 y α = 0. Las dos filas DH quedan:

04 · Código base

Implementa la matriz DH estándar

def A_dh(theta, d, a, alpha):
    ct, st = np.cos(theta), np.sin(theta)
    ca, sa = np.cos(alpha), np.sin(alpha)
    return np.array([
        [ct, -st*ca,  st*sa, a*ct],
        [st,  ct*ca, -ct*sa, a*st],
        [ 0,     sa,     ca,    d],
        [ 0,      0,      0,    1]
    ])

L1, L2 = 2.0, 1.0
q1, q2 = np.radians([0, 90])
T = A_dh(q1, 0, L1, 0) @ A_dh(q2, 0, L2, 0)
plot(T[:2, 3], "Punta")

Comprueba primero el brazo plano. En el UR5 repetirás la misma operación con seis matrices, una por articulación.

06 · Modelo completo

De la tabla a la herramienta

# Cada fila: (a, alpha, d, desfase_theta)
# tabla = [(...), (...), (...), (...), (...), (...)]

def cinematica_directa(q, tabla):
    T = np.eye(4)
    for i, (a, alpha, d, desfase) in enumerate(tabla):
        T = T @ A_dh(q[i] + desfase, d, a, alpha)
    return T

07 · Ruta

Una ruta articular produce una ruta de la herramienta

# Elige dos configuraciones válidas para TU escena, en grados.
q_inicio = np.radians([0, -20, 30, 0, 20, 0])
q_final  = np.radians([15, -35, 45, 10, 30, -10])
ruta_q = [q_inicio + t * (q_final - q_inicio)
          for t in np.linspace(0, 1, 20)]

# Una vez completada tabla:
ruta_punta = [cinematica_directa(q, tabla)[:3, 3]
              for q in ruta_q]
trayectoria(ruta_punta, "Punta predicha")

Observa: los valores articulares cambian de forma interpolada; la punta no tiene por qué seguir una línea recta. Para exigir una ruta cartesiana concreta habrá que resolver cinemática inversa en una etapa posterior.
