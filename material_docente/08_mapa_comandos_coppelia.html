01 · Preparación

Conexión y simulación

La escena y el robot pueden conectarse al mismo puerto. Ambos controlan la misma simulación.

Inicio habitual

Conectar con el UR

Encuentra el robot y la herramienta de la escena. Cambia /UR3 por la ruta real si usas otro modelo.

robot = conectar_ur("/UR3", port=23000)
robot.start_simulation()
Objetos

Conectar con la escena

Permite crear, copiar y eliminar piezas sin exigir un robot concreto.

escena = conectar_escena(port=23000)
Control

Iniciar y detener

Estas instrucciones controlan CoppeliaSim desde Python.

robot.start_simulation()
robot.stop_simulation()
API directa

Acceder a sim

Para comandos propios de CoppeliaSim que no estén envueltos por robot.

sim = robot.sim
estado = sim.getSimulationState()
Cualquier escena

Conexión de bajo nivel

Devuelve el cliente ZeroMQ y sim. Úsalo cuando no necesites las funciones de RobotUR.

client, sim = connect_coppelia(port=23000)
02 · Coordenadas

Puntos y orientación

p[...] describe una pose del TCP en World. Al ejecutar una variable con nombre, aparece un marcador pequeño en la escena.

Posición

Declarar un punto

Solo X, Y y Z en metros. El robot intenta conservar la orientación actual del TCP.

preToma = p[-0.35, 0.335, 0.45]
Pose completa

Agregar orientación

Los últimos tres valores forman un vector de rotación en radianes.

toma = p[-0.35, 0.335, 0.40,
         0, -3.14159, 0]
Lectura

Pose del TCP

Posición World, orientación como cuaternión o vector de rotación.

xyz = robot.tcp_position()
pose = robot.tcp_pose()
giro = robot.tcp_rotation_vector()
Articulaciones

Leer los seis ángulos

q() devuelve las articulaciones actuales en radianes.

q = robot.q()
grados = np.degrees(q)
Referencia

Leer un objeto de la escena

Consulta el centro del objeto en coordenadas World.

centro = robot.posicion("/Cubo_1")
03 · Ruta

Movimiento del robot

Estos comandos requieren la simulación activa. Revisa la postura y la ruta antes de acercarte a piezas o mesas.

Orientación

Alinear la ventosa

1 orienta el eje Z de la herramienta hacia abajo; -1, hacia arriba. Es una ayuda de esta app.

robot.align_z(1)
MoveJ

Ir a una pose

Calcula una postura articular para el destino. El recorrido del TCP puede ser curvo.

robot.movej(preToma)
MoveJ

Ir por ángulos

También acepta seis ángulos articulares en radianes.

robot.movej(np.radians([0, -30, -90,
                         30, 90, 0]))
MoveL

Mover el TCP en línea

Resuelve puntos intermedios de la ruta para que el TCP siga una línea. La ruta debe ser alcanzable.

robot.movel(toma)
robot.movel(preToma)
Cálculo

Calcular IK sin mover

Busca ángulos para una posición World manteniendo la orientación actual. Si no encuentra solución, informa un error.

q_destino = robot.ik([0.35, 0, 0.45])
04 · Respuesta de la escena

Contacto y señales

Los nombres DI, DO y AO dependen del Lua de la escena. Consulta «Señales y equipos» para ver sus etiquetas.

Ventosa

Consultar contacto

Una consulta puntual. Devuelve la pieza dinámica detectada o None.

contacto = robot.detect_contact()
if contacto is not None:
    print(contacto["ruta"])
Ventosa

Bajar hasta tocar

Desciende por pasos hasta detectar una pieza o llegar a la altura mínima.

pieza = robot.lower_until_contact(0.34)
if pieza is not None:
    robot.set_output("DO_00", True)
Salida digital

Activar y soltar

En la escena docente, DO_00 controla la ventosa.

robot.set_output("DO_00", True)
robot.set_output("DO_00", False)
Entrada digital

Leer una señal

DI_01 confirma que la ventosa sostiene una pieza en la escena docente.

estado = robot.read_input("DI_01")
Espera

Esperar confirmación

Espera un valor de entrada. Si no llega antes del tiempo límite, informa un error.

robot.wait_input("DI_01", 1, timeout=3)
Cintas

Velocidad de conveyor

La salida analógica usa mm/s con signo. En la plantilla CEAR, el rango es de −500 a +500 mm/s.

robot.set_analog_output("AO_00", 80)
robot.set_analog_output("AO_00", -80)
robot.set_analog_output("AO_00", 0)
05 · Preparar prácticas

Objetos desde Python

Las posiciones son World y señalan el centro. Un objeto nuevo es dinámico y respondable por defecto.

Crear

Fabricar un cubo

El lado está en metros. En este ejemplo mide 10 cm y su centro queda a 40 cm de altura.

escena = conectar_escena(port=23000)
cubo = escena.create_cube(
    "Cubo_1", [0.35, 0, 0.40], lado=0.10
)
Duplicar

Copiar sobre una mesa

Con sobre solo escribes X e Y. La app calcula Z para que la pieza aparezca apoyada. Usa las rutas reales de tu escena.

copia = escena.copy_object(
    "/CuboPlantilla", "Cubo_2",
    [0, 0.35], sobre="/Mesa"
)
Fijo

Crear un soporte estático

dinamico=False deja el cubo fijo. Una pieza para la ventosa debe ser dinámica.

soporte = escena.create_cube(
    "Soporte", [0.6, 0, 0.05],
    lado=0.10, dinamico=False
)
Eliminar

Retirar un objeto creado

Solo elimina objetos creados por la misma instancia escena; no borra la plantilla original.

escena.delete_object(cubo)
escena.delete_object(copia)

Prepara los objetos antes de iniciar la simulación. Sin sobre, Z indica el centro: si la pieza queda alta, caerá por gravedad. Coppelia puede restaurar el estado inicial al detener; guarda la escena si quieres conservar los objetos entre sesiones.

06 · Modelo matemático

DH y cinemática

La tabla DH sirve para estudiar el modelo. Actualmente movej y movel resuelven IK con la geometría de CoppeliaSim.

DH

Configurar la tabla

Seis filas (a, d, alpha) en metros y radianes. Los valores dependen del modelo y de los marcos elegidos.

robot.set_dh(tabla_DH)
FK

Calcular T06

Usa los seis ángulos actuales y la tabla configurada. Devuelve una matriz 4×4; no mueve el brazo.

q = robot.q()
T06 = robot.forward_kinematics(q)
07 · Lógica del cuaderno

Python y panel programable

Estas estructuras permiten decidir qué hacer con los datos de la escena y mantener controles visibles durante una ejecución.

Condición

Decidir con if

Activa una salida solo cuando el sensor detecta una pieza.

if robot.detect_contact() is not None:
    robot.set_output("DO_00", True)
Función

Guardar una acción

Una función queda disponible para las celdas siguientes del cuaderno.

def soltar():
    robot.set_output("DO_00", False)

soltar()
Panel

Crear controles

El panel muestra un deslizador, un botón y una luz. Python debe leerlos dentro del programa.

panel = PanelControl()
velocidad = panel.deslizador("Cinta", -200, 200, 0)
parar = panel.boton("Detener")
indicador = panel.luz("En marcha")
Bucle

Leer el panel

El botón termina el bucle. Una pausa breve deja tiempo para actualizar los controles.

import time
while not parar.pulsado():
    robot.set_analog_output(
        "AO_00", velocidad.valor
    )
    time.sleep(0.05)
robot.set_analog_output("AO_00", 0)
