## SIMPY - CEAR 0.3.0

Primera versión pública de SIMPY - CEAR, el cuaderno Python para CoppeliaSim Edu.

- Nombre e identidad visual SIMPY - CEAR, con barra de título integrada.
- Ventana de inicio que muestra la búsqueda, descarga e instalación silenciosa de actualizaciones.
- Marco 3D con avisos de error visibles y panel de señales y equipos simplificado.
- Creación y copia de objetos desde Python con `dinamico=0/1` y `respondable=0/1`.
- Código fuente de la aplicación publicado bajo licencia MIT.

El instalador incluye el cuaderno y Python. CoppeliaSim Edu se instala por separado.
