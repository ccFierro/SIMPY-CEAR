## SIMPY - CEAR 0.3.1

- El fondo de ambos temas se integra con la barra de título.
- El panel de señales destaca direcciones como `DI_01`, `DO_00` y `AO_00`.
- El Marco 3D organiza los mandos XY, Z y rotación en una fila compacta.
- Guía con pestañas de conexión, movimiento, señales, objetos y Python. Se corrigió su botón de apertura.
- El editor sugiere métodos al escribir `robot.` o `escena.`; `Ctrl+Espacio` sigue disponible.
- `robot.fk()` lee la pose actual del TCP y `robot.fk(q)` calcula una pose desde la geometría de CoppeliaSim sin mover el brazo. La guía de movimiento ya no requiere DH.

Las funciones DH anteriores permanecen para abrir actividades guardadas. CoppeliaSim Edu y las escenas se instalan por separado.
